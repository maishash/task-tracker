TASK TRACKER

A simple and efficient command-line Task Tracker application built with Python. This project helps you manage your daily tasks by allowing you to add, update, delete, and track the status of your tasks. It uses a JSON file for persistent data storage.

Features

* Add Tasks: Create new tasks with unique IDs.
* Update Tasks: Modify the description of existing tasks.
* Delete Tasks: Remove tasks from your list.
* Change Status: Easily mark tasks as `in-progress` or `done`.
* List Tasks: View all tasks, or filter them by status (`todo`, `in-progress`, `done`).
* Persistent Storage: All tasks are saved automatically to `tasks.json`.

Prerequisites

* Python 3.x installed on your machine.

Installation

1. Clone this repository:
git clone https://github.com/maishash/task-tracker

2. Navigate into the project directory:
cd task-tracker

Usage

You can run the script using Python:
python task-cli.py

(Note: Ensure you have your `tasks.json` file in the same directory for data persistence.)*
Project Structure

* `task-cli.py`: The main Python script containing the `Task` class and management functions.
* `tasks.json`: A JSON file where your task data is stored locally.
